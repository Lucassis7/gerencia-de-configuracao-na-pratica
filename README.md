# AgendaFácil

## Sobre o Projeto

O AgendaFácil é um sistema web simples para gerenciamento de agendamentos.

## Objetivo

Permitir que usuários realizem e consultem agendamentos de maneira rápida e organizada.

## Funcionalidades

- Cadastro de agendamentos
- Consulta de agendamentos
- Cancelamento de agendamentos
